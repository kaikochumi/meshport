# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.5.x | Yes |
| 0.4.x | No |

## Reporting a vulnerability

Use GitHub's private vulnerability reporting on this repository rather than a public issue.

Meshport decodes and converts models entirely inside the browser. It talks only to Tripo and Meshy hosts (tripo3d.ai, tripo3d.com, and meshy.ai) with the session your browser already has, and it never uploads your models anywhere. A report about data leaving the browser, or about one site reading another site's data through the extension, is exactly the kind we want first.
